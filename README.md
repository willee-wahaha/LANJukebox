# LANJukebox

## Requirements

- Python 3.14+
- Node.js 24
- FFmpeg

Set `FFMPEG_PATH` in `.env` if your ffmpeg is not in global path.

## Run

```
# install dependecies
./install.ps1

# run server
./run.ps1 
```
